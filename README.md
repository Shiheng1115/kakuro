# 數和練習場

給新手的數和（Kakuro）練習網站。

網站：https://shiheng1115.github.io/kakuro/

## 玩法

1. 在白格填入 1 到 9。
2. 黑格裡的三角形像屋頂，蓋在哪一段白格上，裡面的數字就是那一段的和：底邊朝下的三角形是下面那一欄的和，底邊朝右的三角形是右邊那一列的和。
3. 同一段裡的數字不能重複。

## 網站功能

- 首頁有「選擇題目」和「規則說明」兩個入口
- 選擇題目頁用 3×3 表格排列：橫向是難度，直向是大小，每格兩題；已完成的題目會標示出來
- 遊戲中隨時可以按「回選擇題目」換題，瀏覽器的上一頁也可以用
- 三種大小：6×6、8×8、10×10（大小包含提示用的黑格）
- 三種難度：簡單、中等、困難，每種各 2 題，共 18 題
- 點格子後用鍵盤或畫面上的數字鍵輸入，方向鍵可以移動
- 同一段填了重複數字時會立刻變色
- 全部填對時會自動顯示完成，填錯的地方不會提示
- 「組合提示」會列出選取格所在段落的所有數字組合
- 計時器，進度會自動存在瀏覽器裡，下次打開可以接著玩

## 題目怎麼來的

題目由程式產生，每一題都經過驗證：

- **只有一個答案。**
- **可以純靠推理解完，不需要猜。**

難度依「每段有幾格」和「需要用到的推理」來分，推理步驟是用模擬人類解題的程式判定的：

| 難度 | 每段格數 | 需要用到的推理 |
|---|---|---|
| 簡單 | 最多 4 格，大部分是 2～3 格 | 只靠「這段的和只有哪幾種組合」和橫直交叉取交集；至少一半的段落只有一種組合 |
| 中等 | 最多 5～6 格 | 推理方式和簡單相同，但段落較長、組合較多 |
| 困難 | 最多 5～6 格 | 需要把整段所有排列方式都考慮進去 |

難度是程式分級，沒有經過大量真人試玩，體感難度可能和標示略有不同。
